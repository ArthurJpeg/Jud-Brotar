# 🥋 CT Judô Brotar

Website institucional desenvolvido para o **Centro de Treinamento Judô Brotar**, localizado em Teresina - PI.

O projeto foi criado com o objetivo de apresentar o centro de treinamento, suas modalidades, horários e informações de contato, além de facilitar o agendamento de aulas experimentais.

## 🌐 Sobre o projeto

O site apresenta as principais informações do CT Judô Brotar de forma simples, moderna e responsiva.

A página reúne informações sobre o centro de treinamento, modalidades oferecidas, horários das turmas, estrutura, filiações e formas de contato.

Também foi desenvolvido um sistema para facilitar o **agendamento de aulas experimentais pelo WhatsApp**, permitindo que o interessado informe seus dados, escolha a modalidade e selecione uma turma antes de iniciar a conversa com o CT.

## ✨ Funcionalidades

- Página institucional do CT Judô Brotar
- Layout responsivo para desktop, tablet e dispositivos móveis
- Menu de navegação responsivo
- Apresentação da estrutura do centro de treinamento
- Seção dedicada ao Judô
- Seção dedicada ao Jiu-Jitsu
- Exibição dos horários das turmas
- Informações sobre filiações esportivas
- Integração com WhatsApp
- Integração com Instagram
- Integração com Google Maps
- Formulário para agendamento de aula experimental
- Seleção dinâmica de modalidade e horário
- Geração automática da mensagem para WhatsApp
- SEO básico
- Open Graph para compartilhamento em redes sociais
- Design adaptado à identidade visual do CT

## 🥋 Modalidades

### Judô

Modalidade principal do CT Judô Brotar, com turmas destinadas a diferentes faixas etárias, incluindo crianças e adultos.

### Jiu-Jitsu

Modalidade oferecida em parceria com a equipe **Warriors Fighter Brazilian Jiu-Jitsu**.

## 📲 Agendamento de aula experimental

O site possui um formulário interativo para agendamento de aulas experimentais.

O usuário informa:

- Nome
- Idade
- Modalidade
- Turma/horário de interesse

Após o preenchimento, o sistema gera automaticamente uma mensagem com essas informações e abre o **WhatsApp do CT Judô Brotar**, deixando a mensagem pronta para envio.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo
- **CSS3** — estilização, responsividade e identidade visual
- **JavaScript** — interatividade, menu mobile, modal e integração com WhatsApp

## 📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela.

Foram implementadas adaptações para:

- Desktop
- Notebook
- Tablet
- Smartphone

No mobile, elementos como navegação, cards, seções e informações de horários são reorganizados para melhorar a experiência de uso.

## 🎨 Interface

A identidade visual utiliza principalmente tons de:

- Azul
- Laranja
- Dourado
- Creme

O projeto utiliza elementos visuais inspirados no **tatame**, além de tipografia e componentes voltados à identidade esportiva do CT Judô Brotar.
